# Object-Detection
Objektif projek :
- Membangunkan model AI Image Classification yang dapat mengenal pasti dan mengelaskan bahan kitar semula kepada tiga kategori iaitu botol plastik, kertas/kotak dan tin aluminium.
- Menguji prestasi model AI menggunakan imej baharu bagi menilai ketepatan pengelasan dan confidence score bagi setiap kategori bahan kitar semula.
- Membangun dan deploy aplikasi web (FastAPI + Pydantic) yang menerima input webcam/imej dan memaparkan prediction serta confidence score.
